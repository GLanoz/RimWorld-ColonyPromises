# Colony Promises

Colony Promises lets you make timed promises to individual colonists: a private bedroom, time for recreation, or better equipment. Keeping a promise improves their mood and trust in the colony's leadership; breaking or withdrawing it lowers both. Promises come from the leadership, so they do not change personal relationships between pawns.

## Requirements

- RimWorld **1.6**. The mod was built against **1.6.4871 rev590**.
- **Harmony**, loaded before Colony Promises.
- No DLC required.

The interface is available in English and Ukrainian. Compatibility with other mods is not guaranteed; see the [API reference and compatibility limits](docs/API.md).
